# Тест-план: интернет-магазин Toolshop

## 1. Объект тестирования
Учебный интернет-магазин инструментов Practice Software Testing (Toolshop):
веб-приложение (Angular) и REST API (Laravel).

- Версия без намеренных багов — поднимается локально в Docker
  из [официального репозитория](https://github.com/testsmith-io/practice-software-testing) (`sprint5`):
  сайт `http://localhost:4200`, API и Swagger `http://localhost:8091/api/documentation`
- Версия с намеренными багами: https://with-bugs.practicesoftwaretesting.com
- Публичная версия https://practicesoftwaretesting.com для автотестов не используется:
  её UI закрыт защитой Cloudflare от ботов

## 2. Цели
- Проверить ключевые пользовательские сценарии: регистрация, вход, каталог, поиск, корзина, оформление заказа.
- Найти и задокументировать дефекты.
- Автоматизировать стабильную часть регресса (smoke + критичные сценарии API и UI).

## 4. Что не тестируем (out of scope)
- Нагрузочное тестирование и безопасность (публичный стенд, нагружать нельзя).
  Исключение — устойчивость поиска к SQL-инъекции и длинным строкам.
- Реальные платежи.
- Админ-панель, отчёты, избранное, аренда.
- Мобильная вёрстка и браузеры, кроме Chromium.

## 5. Подход
- Анализ требований и Swagger до написания тест-кейсов; неточности фиксирую в `docs/requirements-issues.md`.
- Тест-дизайн: классы эквивалентности, граничные значения, сценарные и негативные тесты,
  предугадывание ошибок.
- Исследовательское тестирование на версии with-bugs сессиями с целью (каталог, корзина,
  регистрация и профиль, оформление заказа).
- Тест-кейсы ведутся в Qase (проект Toolshop, 6 сьютов) и дублируются в репозитории:
  [test-cases.md](test-cases.md). Файл импорта в Qase генерируется из него — `qase-import.csv`.
- Известные дефекты в автотестах помечаются `xfail` со ссылкой на дефект.

## 6. Окружения
- Магазин: Docker (локально и в GitHub Actions), версия `sprint5`.
- Браузер: Chromium (Playwright), Chrome для ручных проверок.
- Python 3.12 (CI) / 3.14 (локально), pytest, requests, Playwright, Allure, jsonschema.
- Postman + Newman (Node.js).
- CI: GitHub Actions — на каждый push и ежедневно в 09:00 по Москве.
