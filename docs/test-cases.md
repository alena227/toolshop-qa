# Тест-кейсы: интернет-магазин Toolshop

Тест-кейсы составлены по техникам тест-дизайна: **EP** — классы эквивалентности,
**BVA** — анализ граничных значений, **ST** — сценарный (сквозной) тест,
**NEG** — негативный тест, **EG** — предугадывание ошибок.

**Автоматизация:** ✅ — есть автотест (указан файл), 🖐 — ручная проверка.
**Приоритет:** High — ключевая функция, Medium — важная, Low — второстепенная.

Если тест-кейс проверяет несколько наборов данных (например, четыре неверных пароля),
наборы перечислены в одной строке, а в автотесте они оформлены через `parametrize`.
